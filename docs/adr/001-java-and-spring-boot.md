# ADR-001: Use Java 21 and Spring Boot

## Status
Accepted

## Context
Sentinel needs strong typing, mature concurrency, a large ecosystem for
security and testing and skills that match enterprise hiring demand.

## Decision
Java 21 with Spring Boot 3.

## Consequences
+ Mature tooling, strong job market, great fit for fintech
- More boilerplate than some alternatives; heavier startup time
